TOOL EXECUTION FLOW
================================================================================

Typical Quote Generation Workflow:

Step 1: Client Management
  ├─ db.find_or_create_client("Acme Corp")
  │  └─ Returns: {id: 123, name: "Acme Corp", email: "..."}
  └─ Time: ~50ms (DB connection overhead)

Step 2: Build Quote Items
  ├─ utils.prepare_quote_items(["WEB-ECOMM", "SEO-OPT"])
  │  └─ Returns: {items, total_ht: 5000, tax: 1000, total_ttc: 6000}
  └─ Time: ~100ms (catalog lookup)

Step 3: Create Quote in DB
  ├─ db.create_quote(client_id=123, items=[...], totals=[...])
  │  └─ Returns: {id: 456, quote_number: "QTE-abc123", status: "draft"}
  └─ Time: ~200ms (DB insert)

Step 4: Generate Document [APPROVAL REQUIRED]
  ├─ document.generate_excel(quote_id=456, items=[...])
  │  └─ Returns: {file_path: "/data/quotes/...", document_id: 789}
  └─ Time: ~2000ms (file generation)

Step 5: Email Document [APPROVAL REQUIRED]
  ├─ email.prepare(to="customer@example.com", body="...", attachments=[path])
  │  └─ Returns: {status: "prepared", ...}
  │  [HUMAN REVIEW]
  ├─ email.send(to="customer@example.com", ...)
  │  └─ Returns: {status: "sent", ...}
  └─ Time: ~2000-5000ms (SMTP connection + send)

Total Time: ~10-12 seconds
